# 출장보고서

[출장보고서 양식 파일 열기](https://drive.google.com/file/d/10dNsS6f41xpYs_fkz6PZNGtxVxdoh9Pt/view?usp=sharing){ .md-button .md-button--primary }

## 1. 목적

출장 수행 후 업무 결과 보고 및 비용 정산을 위한 필수 제출 서류 기준을 정의함

## 2. 기본 원칙

- 모든 서류는 증빙 가능 자료만 제출
- 파일명은 반드시 규칙에 맞게 작성 ⭐
- 날짜는 YYMMDD 형식 사용
- 동일 학회 참석 시
    - 출장보고서는 1부만 제출 (대표 1인 작성)

## 3. 여비 지급표

- 📌 지역별 숙박비 상한 존재 (여비 규정표 참고 필수)
    - 상한 초과 금액은 개인 부담
    - 예시
        - 서울 숙박비: 100,000원 → 120,000원 결제 시 → 100,000원만 인정
- 주의사항
    - 2인 이상 동일 숙소 이용 시 → 투숙자 명단 증빙 필수 제출
      - 호텔에 요청 시 invoice에 동반 투숙객 이름 추가해주거나, 별도의 숙박 확인서 발급 해줌. 
    - [여비 규정표 참고](https://jbuh-skin-microbiome.github.io/lab-handbook-mkdocs/graduate-school/conference-attendance/#1_1)

## 4. 제출 서류 목록

### 1) 교통비

- 제출 서류
    - 버스, 기차 이용 영수증 (왕복, 날짜 나오도록)
    - 예시
- 파일명 규칙

```text
1.교통_이름_날짜.pdf
# 예: 1.교통_김소연_260410.png/jpeg/pdf
```

- 추가 확인 사항
    - 시내버스/택시비는 교통비에 포함되지 않아 지원 불가

### 2) 숙박비

- 제출 서류
    - 숙박 영수증 (숙박 날짜 포함 필수)
    - 예약 내역 (예약자 및 투숙자 이름 포함)
- 파일명 규칙

```text
2.숙박_이름_날짜.pdf
# 예: 2.숙박_김소연_260410.pdf
```

- 추가 확인 사항
    - 숙박 영수증에 숙박 날짜 미기재 시 인정 불가
    - 2인 이상 숙박 시:
        - 호텔에 요청하여 투숙자 명단 제출 필수
- Tip
    - 공식 사이트에서 예매 시 투숙 명단 복수 추가 가능
    - 예매 대행 사이트 이용 시 전화로 더블체크 & 체크인 시 가능 여부 추가 문의

### 3) 학회 등록비

- 제출 서류
    - 학회 홈페이지 캡쳐 (학회 이름, 학회 날짜 나오게)
    - 학회 등록영수증
    - 학회 등록 완료 메일
        - 이메일 창에서 - [인쇄] - .pdf로 저장
- 파일명 규칙

```text
3.학회_이름_종류.pdf
# 예: 3-1.학회_홈페이지.pdf
# 3-2.학회_김소연_등록완료메일.png/pdf/jpeg
# 3-3.학회_김소연_등록영수증.png/pdf/jpeg
```

### 4) 참석 증빙

- 제출 서류
    - 학회 등록 확인증
    - 명찰 또는 현장 사진
- 파일명 규칙

```text
3-3.학회_이름_명찰.jpg
```

### 5) 학회 활동 증빙

- 제출 서류
    - 초록(Abstract)
    - 프로그램북
    - 포스터 (해당자)
    - 발표자료 (해당자)
- 파일명 규칙

```text
4.초록_이름_제목.png
5.포스터_이름_제목.pdf
6.프로그램북.png

# 4.초록_김소연_Lawseonlla.png/jpeg/pdf/docx (제목은 길면 아예 생략 or 키워드로 축약)
# 5.포스터_김소연_lawsonella.png/jpeg/pdf/docx
# 6.프로그램북
```

### 6) 식비 (필요 시)

- 제출 서류
    - 식비 영수증
        - 일반적으로 제출 제출 불필요 (식비를 별도 정산이 아닌 여비로 지급됨)
        - 단, 증빙이 부족한 경우 현장 체류 증빙을 위해 편의점이나 식당에서의 영수증 지참 권장
- 파일명 규칙

```text
7.식비_이름_날짜.pdf
```

### 7) 출장보고서

- 제출 서류
    - 양식에 맞게 작성
    - [출장보고서_양식.hwpx](https://drive.google.com/file/d/10dNsS6f41xpYs_fkz6PZNGtxVxdoh9Pt/view?usp=sharing) — 121.4KB
- 파일명 규칙

```text
0.출장보고서_팀/이름_날짜.hwpx
# 예: 0.출장보고서_피부과_260412.hwpx
```

- 작성내용
    - 학회 이름/ 학회장 주소/ 날짜/ 참가명단
    - 학회 내용
        - 대표자 1인 작성
        - 개조식으로 작성

```text
1. 출장 목적
o
 -
o
 -
 -
o

2. 발표내용/ 출장 내용/ 학회 내용
o
o
o

3. 기대효과 및 시사점
o
o
 -
o
o

4. 특이점
o
```

- 학회 참석 사진 첨부
- 참고자료 (공무 출장 보고서)

### 8) 서류 전달 시

- 출장보고서 통합본 파일
    - 모든 파일은 출장 보고서 안에 이미지로 추가 
    - 파일 명은 "학회날짜_학회이름_출장보고서_작성자이름.hwpx"
- 담당자에게 메일 작성 시 추가 작성 사항
    - 숙박 포함 여부
    - 식사 제공 여부 

```text
e.g. 이번 출장 건은 학회에서 식사가 제공되었습니다.
e.g. 04월 10일 점심은 학회에서 제공받았습니다.
```
