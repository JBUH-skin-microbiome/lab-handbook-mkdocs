# 졸업시험

> 아래 일정과 기준에는 과거 예시가 포함되어 있습니다. 실제 신청에는 해당 학기의 학과 및 대학원 공지를 확인하세요.

## 종합 시험

- 재학생 : 2022학년도 제1학기말 기준
    - 교과학점 18학점 이상 취득한자 (※ 논문연구학점 무관) → 2학기 이후 신청 가능
- 수료자 : 학점제한 없음
- ※ 합격자 중 수료 후 6년을 경과한자는 다시 응시해야 함
- ※ 휴학자는 응시자격 없음 (단, 복학예정자는 해당 대학에 신청)

## 외국어시험

- 재학생 : 2022학년도 제1학기말 기준 '교과학점 12학점 이상' 취득한 자(선수과목 및 논문연구 제외)
- 수료자 : 학점제한 없음
- ※ 합격자 중 수료 후 6년이 경과한 자는 다시 응시해야 함
- ※ 휴학자는 응시자격이 없음 (단, 복학예정자는 해당 대학에 신청)
