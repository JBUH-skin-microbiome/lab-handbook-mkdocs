### 회의록 작성법 
#### 회의 준비물

- 적을 것 (태블릿, 노트북, 노트)
- 네이버 클로바노트 (녹음 및 스크립트)

#### 회의록 작성 내용 
- 안건
    - 논의 내용
    - 피드백
    - 결정사항
- 일정
- 기한
- 다음회의 일정

#### 회의록 작성 방법
- 개조식으로 작성
- [참고](https://brunch.co.kr/@second-space/34)

```text
# 서술식
이슬람 최대 명절 중 하나인 라마단이 지난 8월 18일에 끝났습니다. 따라서 중동 항로의 거래량과 실제 적재 비율이 다시 늘어날 것으로 보입니다. (라마단 직전의 실제 적재 비율은 95%에 육박했습니다). 또한 중동 항로 선사 협의체에서는 2012년 7월 중 컨테이너 당 300달러의 성수기 할증료를 부과할 예정이었으나 이를 유예했습니다. 
# 개조식:
- **중동 항로 관련 이슈**
  - 라마단 종료 후 중동 항로 물동량 회복 예상 (8/18 ~ )
  - 중동 선사 협의체 성수기 할증료 유예 (300 USD, p136 참조)
```

- 날짜는 년/월/일 순으로 작성
- 시간은 24시간 기준으로 작성
- 글머리 기호 통일할 것
    - 1., 1), (1), - 
- 회의 중 및 회의 직후 작성을 마무리 할 것 (회의록 작성에 많은 시간을 투자하지 말자💥)
- 발언자를 적어야 한다면 이름, 직책 및 발언 정보 추가 (예, CRC간호사, pf김교수, res연구자)

#### 회의록 전달 
- 수요 및 목요일 미팅의 경우 회의담장자가 작성
- 약대 조인트 미팅의 경우 조인트미팅 담당자가 작성
- 개별 프로젝트의 경우 회의 참여 연구원이 작성
    - 타 대학/타부서와 협업 미팅의 경우 회의록 작성 후 당일에 메일로 교수님 전달
    - 컨펌 후 타 대학 및 부서에 메일 전달 (교수님, 참여 연구원 참조에 추가) 


### 프로젝트 회의 자료 양식


##### 1. 표지 
- 프로젝트 제목/날짜/이름 간략하게 작성 

##### 2. 배경

- 연구 질환 설명  
- 질환의 기전 및 미생물과 연관성 문헌조사 결과

##### 3. 연구목표

- 연구 목표

##### 4. 연구 결과

###### 1) 연구 결과 보고 규칙 

- 날짜별로 업데이트
- 장기적인 프로젝트의 경우 update 결과를 맨 상단에 배치

###### 2) 결과 보고 

- 임상 수집 샘플  
    - 대상자의 인구학적 정보 정리  
    - 수집 및 최종 대상자 정리  
    - 수집된 샘플 개수 정리  
    - 수집된 샘플 중 시퀀싱 (NGS) 이 최종적으로 완료된 샘플 정리  
    
- 전처리 결과 보고  
    - 실험 중 Control 디자인  
    - Read count 보고   

- 기초 분석  
    - alpha diveristy  
    - beta diversity  
    - Taxonomy composition  
    - 임상 데이터에 따른 alpha, beta의 결과  
    - differenctial  abundance analysis 사용  
        - wilcoxon rank sum test (민감도분석)  
        - ANCOM-BC2  
        - MaAsLin2  

- Amplicon 추가 분석    
    - 기능 예측: PICRUSt2  

- Shotgun 추가 분석  
    - 기능 예측: Humman, egg-NOG  
    - 독성 분석  
    - 항생제 내성 유전체 분석  
    - Strain level 분석  

- 공통 분석  
    - Network 분석  


##### 5. 추가 실험 및 논의

- 결과 논의
    - 연구 시 어려운점을 교수님과 연구원들에게 논의

- 향후 추가 실험 계획 및 예상 결과



## 저널 클럽

- 피부마이크로바이옴/ 메타게놈/ 피부질환/ 면역질환 관련된 최신 문헌을 소개합니다. 발표 시간은 20–30분 정도 소요되며, 목요일 오전 미팅시간에 진행됩니다.
- 발표자는 발표 1주일 전에 발표 논문을 공유해야 합니다.
