# 실험실습기자재 확충사업 예산요구

## 목적

다음 연도 실험실습기자재 확충사업의 예산 편성을 위해 기존 기자재의 보유·취득·활용 현황과 폐기 처리 비용 수요를 조사하여 제출합니다.

## 작성 서류

| 제출자료 | 작성 기준 |
|---|---|
| 실험실습기자재 보유현황 | 전년도 제출자료를 기준일에 맞게 갱신하고, 새로 확인된 기자재를 추가합니다. |
| 실험실습기자재 취득 현황 | 조사 대상 연도에 취득한 **100만 원 이상**의 물품대장 등록 기자재를 작성합니다. 확충사업 외 예산으로 구매한 기자재도 포함합니다. |
| 실험실습기자재 활용 실적 | 최근 2년 동안 구입한 **3천만 원 이상**의 실험실습기자재를 대상으로 실제 활용 실적을 작성합니다. |
| 내구연한 도과 실험실습기자재 폐기 처리 비용 수요조사 | 확충사업비로 구매한 기자재 중 폐기 비용 수요가 있는 장비를 작성하고, 폐기물 처리업체의 견적서 2부를 첨부합니다. |

## 작성 시 확인할 사항

- 취득 현황에는 냉장실, 각종 사무실, 교수연구실, 연구소 등에서 사용하는 **사무용품 일체를 제외**합니다.
- 활용 실적은 건물, 차량, 보안시설 등 조사 대상이 아닌 항목을 제외하고 **실제 사용한 경우만** 작성합니다.
- 구매 시점이 오래되어 확충사업비 구매 여부를 확인하기 어려우면 수요조사서의 확인불가 항목에 표시합니다.
- 물품취득원장은 취득 현황 작성 시 참고자료로 사용합니다.
