# 의생명연구원 정기 안전보건교육

의생명연구원에서 분기별로 배포하는 교육자료를 이용해 소속별로 시행하는 정기 안전보건교육입니다.

## 교육 개요

| 항목 | 내용 |
|---|---|
| 주관 | 의생명연구원 |
| 주기 | 분기별, 연 4회 |
| 대상 | 의생명연구원으로 4대 보험이 가입된 근무자 |
| 추가 대상 | 4대 보험 가입 여부와 관계없이 임상연구지원센터 내에서 근무하는 사람 |
| 교육 방법 | 분기별 교육자료를 확인한 뒤 소속별 단체교육 시행 |
| 기록 관리 | 교육일지 원본은 실험실에 보관하고 사본을 제출 |
| 제출처 | 임상연구지원센터 318호 또는 해당 분기 안내 메일에 기재된 제출처 |

## 진행 절차

1. 분기별 정기 안전보건교육 안내 메일과 교육자료를 확인합니다.
2. 교육 대상자를 확인하고 부서장 또는 담당자가 단체교육을 진행합니다.
3. 교육일지에 교육일자, 교육내용, 대상자와 서명을 빠짐없이 작성합니다.
4. 교육일지 원본은 실험실에 보관합니다.
5. 사본을 임상연구지원센터 318호에 제출하거나 안내된 방법에 따라 스캔본을 회신합니다.

## 연간 확인 시기

| 분기 | 안내 시기 예시 | 확인할 사항 |
|---|---|---|
| 1분기 | 1월 | 교육자료와 교육일지 수신 여부 |
| 2분기 | 4월 | 교육 시행 및 서명 완료 여부 |
| 3분기 | 7월 | 교육일지 원본 보관 및 사본 제출 여부 |
| 4분기 | 10월 | 연간 교육 기록 누락 여부 |

!!! warning "메일 공지 우선"
    교육 대상, 제출 기한과 제출 방법은 분기별 안내에 따라 달라질 수 있으므로 해당 분기의 안내 메일을 우선 적용합니다.
