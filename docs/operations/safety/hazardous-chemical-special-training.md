# (해당 시 1회) 유해화학물질 특별안전보건교육

## 대상과 주기

유해화학물질을 취급하는 업무에 새로 배치되는 연구활동종사자가 대상입니다. 매년 전원이 반복해서 이수하는 교육이 아니라 **해당 업무에 배치될 때 1회** 실시합니다. 취급 물질이나 업무 내용이 바뀌면 기관 안내에 따라 다시 교육할 수 있습니다.

| 항목 | 내용 |
|---|---|
| 적용 조건 | 유해화학물질 취급 업무에 새로 배치되는 경우 |
| 교육 주기 | 해당 시 1회, 업무 변경 시 재교육 가능 |
| 교육 시간 | 총 16시간 |
| 실시 시기 | 최초 작업 종사 전 4시간 이상 실시, 나머지 12시간은 3개월 이내 분할 가능 |
| 기록 보관 | 3년 |

## 교육 내용

1. 대상 화학물질의 명칭 또는 제품명
2. 물리적 위험성과 건강 유해성
3. 취급 시 주의사항
4. 적절한 보호구의 종류와 사용법
5. 응급조치 요령과 사고 발생 시 대처 방법
6. 물질안전보건자료(MSDS)와 경고표지 확인 방법
7. 특별관리물질의 종류와 관리 방법

## 작성 및 보관 서류

- `특별안전보건교육일지 양식.hwp`
- `유해화학물질 신규등록 및 변경 보고서(규정).hwp`
- 교육자료와 참고자료

교육일지에는 교육 일시, 교육 내용, 교육 대상자와 서명을 기록하고 3년간 보관합니다.

!!! note "교육자료 확인"
    기존 안내 자료에는 16시간 교육자료가 포함되어 있지 않았습니다. 실제 대상자가 생기면 안전관리 담당 부서에 최신 교육자료와 제출 방법을 확인합니다.
