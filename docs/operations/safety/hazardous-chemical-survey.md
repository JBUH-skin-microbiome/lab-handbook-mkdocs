# (연 1회) 유해화학물질 사용 실태조사

## 목적과 주기

전북대학교병원 임상연구지원센터 연구실에서 취급하는 유해화학물질을 확인하고 관련 기록을 관리하기 위한 조사입니다. 산업안전보건법에 따른 병원 안내에 따라 **연 1회** 실시합니다.

| 항목 | 내용 |
|---|---|
| 조사명 | 부서 내 유해화학물질 사용 실태조사 및 관리 |
| 주기 | 연 1회 |
| 제출 절차 | 유해화학물질 조사표 작성 → 부서장 결재 → 담당 부서 회신 |
| 함께 확인할 자료 | 취급 물질의 MSDS, 관리대상 유해물질 목록 |
| 기록 보관 | 3년 |

## 작성 및 제출 서류

- `유해화학물질 조사표.xlsx`
- 취급 물질별 MSDS
- `[별표 12] 관리대상 유해물질의 종류(산업안전보건기준에 관한 규칙).hwp`
- 해당 연도 `부서 내 유해화학물질 사용 실태조사 및 관리 안내.pdf`

## 특별관리물질 및 유해화학물질 취급일지

특별관리물질 또는 유해화학물질을 사용할 때마다 `특별관리물질 취급일지.hwp`를 작성합니다. 취급일지는 조사표와 별도로 관리하며 3년간 보관합니다.

## 확인 사항

- 새 화학물질을 구매하거나 사용하기 전에 MSDS를 확보합니다.
- 신규 물질 등록 또는 기존 물질의 사용 정보가 바뀌면 변경 보고 대상인지 확인합니다.
- 조사표의 보유량과 실제 보관 상태가 일치하는지 확인합니다.
- 제출 전 부서장 결재와 첨부파일 누락 여부를 확인합니다.
