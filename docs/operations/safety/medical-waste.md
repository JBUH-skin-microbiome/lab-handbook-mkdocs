# 의료폐기물 점검

## 원칙

- 안전 관리 담당자가 격주 마다 목요일에 폐기합니다.
- 의료폐기물 전용용기를 사용합니다.
- 사용 시작 시 사용개시일을 기입합니다.
- 보관기간 안에 박스째 폐기합니다.
- 감염성 폐기물이 일반폐기물과 섞이지 않도록 분리 보관합니다.

## 관리 점검

| 항목 | 내용 |
|---|---|
| 점검명 | 의료폐기물 관리 점검 |
| 점검 주체 | 병원 환경부서 |
| 점검 주기 | 월별 |
| 주요 점검 항목 | 사용개시일 작성 여부, 보관기간 준수 여부, 전용용기 사용 여부, 폐기물 분리보관 여부 |
| 본 실험실 관리 사항 | 의료폐기물 전용용기 사용, 사용개시일 기재, 보관기간 준수, 감염성 폐기물 혼합 방지 |
| 기록 관리 | 점검 결과 또는 지적사항 발생 시 조치 내역을 기록·보관 |

## 폐기물 박스 수령

- 임상연구지원센터 318호
