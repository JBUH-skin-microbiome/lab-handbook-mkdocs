# 위험성 평가

본 실험실은 의생명연구원 기준에 따라 연 1회 위험성 평가를 시행합니다. 위험성 평가는 실험실 내 유해·위험요인을 사전에 확인하고 사고 발생 가능성과 중대성을 평가하여 개선조치를 수립하기 위한 절차입니다.

| 항목 | 내용 |
|---|---|
| 평가명 | 의생명연구원 위험성 평가 |
| 주기 | 연 1회 |
| 대상 | 본 실험실 내 연구활동, 실험장비, 화학물질, 생물학적 물질, 폐기물 관리 등 |
| 주요 평가 항목 | 유해·위험요인 확인, 사고 가능성 평가, 개선대책 수립, 조치 결과 기록 |
| 기록 보관 | 관련 서류는 각 부서 또는 실험실에서 3년 이상 보관 |
| 관리 방식 | 평가 결과 및 개선조치 내역을 실험실 안전관리 서류함에 보관 |
