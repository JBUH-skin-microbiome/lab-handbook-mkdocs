## 일상점검

전북대학교 연구실안전관리시스템은 안전점검 항목으로 일상점검, 정기점검과 정밀안전진단을 제시합니다. 원문 작성 시점에는 본 실험실이 전북대학교 연구실안전관리시스템에 연구실로 등록되어 있지 않아 시스템 기반 일상점검 작성 대상에 해당하지 않는다고 기록되어 있습니다. 현재는 의생명연구원 자체 교육, 위험성 평가, 의료폐기물 점검과 내부 안전관리 기록을 중심으로 관리합니다.

향후 점검 대상으로 등록되면 다음 기준으로 작성·보관합니다.

| 항목 | 내용 |
|---|---|
| 적용 조건 | 연구실안전관리시스템 등록 또는 점검 대상 지정 시 |
| 점검 주기 | 기본 주 1회 또는 기관 안내 기준에 따름 |
| 작성 방식 | 매월 1일 점검표 출력 후 수기 작성 |
| 점검 표기 | O, △, X 방식으로 기록 |
| 확인 방식 | 도장 대신 서명 사용 |
| 보관 위치 | 연구실 안전관리 서류보관함 |
| 점검 대상일 | 실제 연구활동을 수행하는 날 기준 |
| 조치 관리 | △ 또는 X 항목은 개선조치 후 조치내용 기록 |
