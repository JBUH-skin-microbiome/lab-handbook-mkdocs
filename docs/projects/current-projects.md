# 현재 프로젝트 현황

연구실에서 진행하는 프로젝트와 업무 상태를 확인합니다. Google 계정 권한이 있는 구성원은 아래 Looker Studio 대시보드에서 담당자와 상태를 선택해 확인할 수 있습니다.

!!! info "JBSM Project Dashboard"
    대시보드에서 전체 프로젝트 수와 태스크 수, 진행 상태별 현황을 확인할 수 있습니다. `Assignee`와 `Status` 필터를 사용하면 담당자와 상태별로 조회할 수 있습니다.

    [프로젝트 대시보드 열기](https://datastudio.google.com/reporting/d519b14e-bd0e-4bab-aa5a-0867d55e114b/page/FmHEG){ .md-button .md-button--primary target=_blank }

!!! info "데이터 갱신"
    이 대시보드는 연구실 내부 `Lab Project`의 `Project`와 `Task` 시트를 기준으로 갱신합니다. Google 계정 권한이 있는 구성원만 열람할 수 있습니다. Funding, IRB 및 내부 메모는 표시하지 않습니다.
