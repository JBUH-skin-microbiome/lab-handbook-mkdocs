# 마이크로바이옴 용어집

마이크로바이옴 공부와 실험·분석에서 자주 접하는 기본 용어를 정리합니다.

## 기본 용어

| 용어 | 약어 | 뜻 |
| --- | --- | --- |
| Microbiota | — | 특정 환경에 존재하는 미생물 군집. |
| Microbiome | — | 특정 환경의 미생물 군집을 가리키는 말. 문헌에 따라 그 유전정보와 주변 환경까지 포함하므로 정의를 함께 확인합니다. |
| Amplicon sequence variant | ASV | 시퀀싱 오류를 보정하는 과정에서 추론한 서로 다른 앰플리콘 서열 단위. |
| Operational taxonomic unit | OTU | 설정한 서열 유사도 기준에 따라 서열을 묶은 분석 단위. |
| Alpha diversity | α-diversity | 한 샘플 안의 다양성. 지표에 따라 풍부도, 균등도 또는 계통적 다양성 등을 반영합니다. |
| Beta diversity | β-diversity | 샘플 사이의 미생물 군집 구성 차이. 거리 또는 비유사도 지표로 평가합니다. |

ASV와 OTU는 분석 단위이며, 생물학적 종(species)과 반드시 일치하지 않습니다.
