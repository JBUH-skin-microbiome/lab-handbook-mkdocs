# 깃허브 관리

## 바로가기

- [피부마이크로바이옴연구실 GitHub](https://github.com/JBUH-skin-microbiome)
- [연구실 홈페이지 저장소](https://github.com/JBUH-skin-microbiome/JBUH-skin-microbiome.github.io)
- [연구실 매뉴얼 저장소](https://github.com/JBUH-skin-microbiome/lab-handbook)

## 관리 원칙

- 저장소 이름과 설명만 보고도 용도를 알 수 있게 작성합니다.
- 공개 저장소에는 개인정보, 환자 자료, 비밀번호, 토큰과 접속 키를 올리지 않습니다.
- 변경 내용을 확인할 수 있도록 커밋 메시지를 구체적으로 작성합니다.
- 배포용 저장소를 수정한 뒤에는 Actions 결과와 실제 페이지를 확인합니다.
- 구성원이 연구실을 떠나면 저장소 권한을 점검합니다.
