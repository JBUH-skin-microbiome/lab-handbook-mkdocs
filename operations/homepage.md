## 수정할 때 확인할 사항

- 공개해도 되는 내용인지 먼저 확인합니다.
- 구성원 연락처와 사진은 당사자 확인 후 올립니다.
- 수정 후에는 데스크톱과 모바일 화면을 모두 확인합니다.
- GitHub Pages 배포가 끝난 뒤 실제 페이지에서 링크와 이미지가 열리는지 확인합니다.

## 홈페이지 서식

- 긴 설명은 검은색, 짧은 강조 문구는 남색(`#1a0076`)을 사용합니다.
- 한글과 바닥글은 `Gothic A1`, 영문은 `Vollkorn`을 사용합니다.
- 기본 강조색은 `#191970`입니다.
