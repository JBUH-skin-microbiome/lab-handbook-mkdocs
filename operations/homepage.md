## 수정할 때 확인할 사항

- 먼저 공개해도 되는 내용인지 확인합니다.
- 구성원의 연락처와 사진은 당사자에게 확인한 뒤 올립니다.
- 수정한 내용은 데스크톱과 모바일 화면에서 각각 확인합니다.
- GitHub Pages 배포가 끝나면 실제 페이지에서 링크와 이미지가 제대로 열리는지 확인합니다.
