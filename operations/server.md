# 서버 관리

서버 주소, 계정, 접속 키와 방화벽 정보는 공개 문서에 적지 않습니다. 접속 정보와 담당자 기록은 연구실 내부 문서에서 확인합니다.

## 관리 항목

- 계정 발급·변경·회수 내역
- 저장 공간과 백업 상태
- 운영체제 및 주요 프로그램 업데이트
- 장애 발생 시간, 원인과 조치 내용
- 장비별 담당자와 점검일

서버 설정을 바꾸기 전에는 현재 설정을 기록하고, 작업이 끝난 뒤 접속과 분석 환경이 정상인지 확인합니다.
